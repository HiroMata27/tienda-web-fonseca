# tienda-web-fonseca
Laboratorio 1
## Arquitectura cliente-servidor
Una aplicación web separa responsabilidades entre un cliente (el navegador, que renderiza la interfaz y captura la interacción del usuario) y un servidor (que expone datos y lógica de negocio a través de una API). El proyecto de este curso sigue este modelo: un front-end realizado en github con Html y Css que permita mostrar un negocio en la WEB.
## Git y control de versiones
El proyecto se trabaja de manera individual. Se realiza commit y push y se deja en el repositorio con una dirección que se coloca en el Word donde van los datos del estudiante el código del index.html y del styles.css.
